Privacy Policy – KR What If Uploader

Last updated: 9 November 2026

Who uses this app

KR What If Uploader is used only by the owner of the YouTube channel KR's What If Explained, to manage that one channel. It has no other users.

What Google user data it accesses

Through the YouTube API Services, with the channel owner's permission, the app:

  • uploads the channel's own videos and thumbnails;
  • sets and updates titles, descriptions and tags of those videos;
  • posts comments on the channel's own videos;
  • reads view and watch-time statistics of the channel's own videos.

How the data is used and stored

The data is used only for the purposes above. The OAuth token that gives access is stored encrypted as a GitHub Actions secret, which only the channel owner's automation can read. Video statistics are kept only as long as needed to compare title and thumbnail versions.

Sharing

No Google user data is sold, shared with or transferred to anyone. It is not used for advertising.

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

Access can be removed at any time from Google Account → Security → Third-party connections. The stored token can also be deleted from the GitHub repository's secrets.
